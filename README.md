# Trading212-to-StockEvents-Converter
A useful tools that converts the Trading 212 transaction history output to a useable file by Stock Events for importing transactions.

# How To Use

**Step 1** Export your history in Trading 212 with only Orders selected.

<img width="418" height="739" alt="image" src="https://github.com/user-attachments/assets/9c42ce37-0170-437b-a4da-ca6cce1f864d" />


**Step 2** Click and drag the exported document into the converter.

<img width="1068" height="776" alt="image" src="https://github.com/user-attachments/assets/adeb9c7f-1f86-472c-ae82-71bd4bd29126" />


**Note** Stock Events uses a different symbol system for certain instruments - for example the UK Company BAE which has the stock ticker BA is written as BA.LSE - this is likely because it conflicts with another instrument listed in another market. You can bypass this by cross-checking your holdings against the tickers in Stock Events and adding them to the Symbol Converter. Saved mappings will persist.

<img width="1024" height="1022" alt="image" src="https://github.com/user-attachments/assets/186af23e-a70f-456d-82a6-09d8c42ef984" />


**Step 3** Download the converted document and import into stock events.
