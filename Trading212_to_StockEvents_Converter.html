Trading212 and Stock Events don't always use the same ticker for a holding. This table tells the converter what each Trading212 ticker should be called in Stock Events. Any ticker that isn't listed comes out with a blank Symbol.

Adding your own holdings

  1. Find the Trading212 ticker. It's in the Ticker column of your Trading212 CSV, e.g. VUAG. Any tickers this page can't match are listed in the yellow warning after you convert.
  2. Find the Stock Events symbol. Search for the holding in the Stock Events app and note the symbol it uses. In the default list, London-listed holdings end in .LSE (e.g. VUAG.LSE) and US-listed ones keep their ticker as-is (e.g. NVDA).
  3. Add a line in the box below as Trading212 ticker,Stock Events symbol, for example: 
    TSLA,TSLA
ISF,ISF.LSE
  4. Click Save mappings. If you've already loaded a CSV, the preview updates straight away.

Good to know

  • One mapping per line, with a single comma between the two values and no spaces needed.
  • Upper or lower case doesn't matter for the Trading212 ticker.
  • To change a mapping, edit its line. To remove one, delete its line.
  • Lines starting with # are ignored, so you can use them as notes.
  • Saved mappings are remembered in this browser on this computer only. Reset to defaults brings back the original list.
  • To share your list with someone else, open this file in a text editor (e.g. Notepad), find DEFAULT_MAP near the bottom and add entries in the same style, e.g. ["TSLA","TSLA"],. Save it, and anyone who opens that copy gets your mappings as the defaults.
